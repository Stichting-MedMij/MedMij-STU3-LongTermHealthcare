# MedMij-STU3-LongTermHealthcare
This repository contains HL7 FHIR STU3 compliant conformance materials for MedMij STU3 Long-term Healthcare, also known as "Basisgegevens Langdurige Zorg+" or "BgLZ+". This project is currently in a pre-publication status and can therefore not be considered stable.

The implementation guide for this project, also in a pre-publication status, can be found on [Simplifier](https://simplifier.net/guide/medmij-stu3-long-term-healthcare-ig).

This repository is maintained by MedMij.
